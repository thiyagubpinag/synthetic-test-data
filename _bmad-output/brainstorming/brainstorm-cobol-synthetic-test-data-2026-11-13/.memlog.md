- (technique) started Five Whys
- (idea by coach) Why do CICS programs abend on synthetic data? Because the byte alignment of the fields is off.
- (idea by coach) Why is the byte alignment off? Because FILLER fields and REDEFINES are not modeled with precise length calculations.
- (idea by coach) Why are they not modeled precisely? Because the parsing engine ignores the raw character offsets and relies solely on field order.
- (idea by coach) Why does it rely on field order? Because it does not calculate absolute start and end indices for each variable in the COBOL structure.
- (idea by coach) Why doesn't it calculate absolute offsets? Because it lacks a memory layout engine that simulates the mainframe's physical storage layout (e.g. COMP vs COMP-3 vs DISPLAY spacing).
- (idea by coach) Root Cause: Implement a physical memory simulator (Memory Layout Engine) inside the extraction and generation subagents.
- (idea by coach) Why do nested REDEFINES overwrite wrong variables? Because Python structures don't natively share memory overlays.
- (idea by coach) Why don't they share memory overlays? Because Python attributes are independent variables in memory.
- (idea by coach) Why are they independent? Because standard dictionary serialization models them as hierarchical nested elements.
- (idea by coach) Why model as nested elements? Because standard JSON doesn't support pointer overlays or address sharing.

- (technique) started Failure Analysis
- (idea by coach) What broke: A test suite failed because '123.45' was written in COMP-3 as '01 23 45' without a sign nibble, leading to S0C7 abends.
- (idea by coach) Why: The generator script treated COMP-3 as simple packed decimal without the trailing sign nibble ('C' for positive, 'D' for negative, 'F' for unsigned).
- (idea by coach) Lesson: Mainframe data formats are extremely picky about sign representation in hex nibbles (low-order digit holds the sign).
- (idea by coach) Mitigation: Implement a strict binary verification stage in the generator that validates sign nibble compliance on all COMP-3 fields.
- (idea by coach) Failure: REDEFINES overlapping fields were generated with conflicting values (e.g. both First-Name and Policy-Num were filled, corrupted each other).
- (idea by coach) Why: The generator did not know that only one REDEFINES variant can be populated per record stream.
- (idea by coach) Lesson: Redefined variables occupy the exact same physical byte space and are mutually exclusive.
- (idea by coach) Mitigation: Implement mutually exclusive logic path selectors so that only the chosen branch's fields are generated, and other overlapping bytes are cleared/padded.
- (idea by coach) Failure: Large test file failed load because record lengths were short. Why: Trailing blanks were trimmed. Lesson: Preserve raw lengths.
- (idea by coach) Mitigation: Explicitly pad records to fixed lengths using spaces before writing.

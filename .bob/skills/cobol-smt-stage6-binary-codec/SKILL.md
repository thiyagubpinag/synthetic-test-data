# Stage 06: Binary Memory Overlay & EBCDIC Codec

**Approach:** 100% Deterministic (Python `ctypes`, `struct`, `memoryview` & `codecs`)  
**Input:** `enriched_record.json` and Copybook schema definitions  
**Output:** `memory_overlay.py`, `<entity>_records.bin`, and `<entity>_records_ebcdic.txt`

## Purpose & Architecture Alignment
As defined in `pipeline_architecture.html` Stage 06:
- Mainframe data exchange requires exact byte-level physical layouts conforming to z/Architecture conventions.
- AI cannot reliably synthesize raw bit/byte binary representations.
- Stage 06 compiles COBOL copybook layouts directly into Python `ctypes.BigEndianStructure` memory overlays.
- Accurately encodes:
  - **EBCDIC (IBM cp1047 / cp500 / cp037)** for character/alphanumeric fields.
  - **Packed Decimal (COMP-3)** with proper nibble layout and sign nybbles (`0xC` positive, `0xD` negative, `0xF` unsigned).
  - **Binary Fixed-Point (COMP / COMP-4 / COMP-5)** in Big-Endian representation (`int16`, `int32`, `int64`).
  - **REDEFINES and Group Overlays** using shared `ctypes.Union` / `memoryview` slices.

---

## Detailed Execution Steps

### 1. Copybook to ctypes Compilation
1. Parse record structure from Stage 01 schema:
   - For character fields (`PIC X(n)`): define `ctypes.c_char * n`.
   - For COMP fields (`PIC 9(4) COMP`): define `ctypes.c_int16` (Big Endian).
   - For COMP-3 fields (`PIC 9(n) COMP-3`): calculate packed byte size $\lceil (n + 1) / 2 \rceil$ and implement nibble encoder.
   - For REDEFINES: define `ctypes.Union` containing alternative field mappings over identical memory offsets.

### 2. Byte Packing & Encoding
1. Ingest enriched test records from `enriched_record.json`.
2. Format values according to COBOL usage rules:
   - Convert string values to EBCDIC byte strings (`str.encode('cp1047')`).
   - Pack numeric decimals into COMP-3 hex sequences (e.g. `25000.00` with `PIC 9(6)V99` -> `0x02 0x50 0x00 0x0C`).
   - Pad strings with spaces (`0x40` in EBCDIC) and numbers with leading zeroes.

### 3. Binary Export & Verification
1. Output generated byte stream to raw binary file (`.bin` / `.dat`).
2. Generate companion hex-dump verification report for mainframe batch ingestion or test harness playback.

## Python Binary Codec Engine (`memory_overlay.py`)

```python
import ctypes
import binascii

def pack_comp3(val_str: str, digits: int, signed: bool = True) -> bytes:
    """Packs numeric string into IBM COMP-3 packed decimal bytes."""
    clean_val = val_str.replace('.', '').replace('-', '').zfill(digits)
    # Append sign nibble: 'C' (pos), 'D' (neg), 'F' (unsigned)
    sign = 'D' if val_str.startswith('-') else ('C' if signed else 'F')
    nibbles = clean_val + sign
    if len(nibbles) % 2 != 0:
        nibbles = '0' + nibbles
    return bytes.fromhex(nibbles)

def unpack_comp3(packed_bytes: bytes, scale: int = 0) -> float:
    """Unpacks IBM COMP-3 packed decimal bytes to float."""
    hex_str = packed_bytes.hex().upper()
    digits = hex_str[:-1]
    sign = hex_str[-1]
    val = int(digits)
    if sign == 'D':
        val = -val
    return val / (10 ** scale)

class LoanCustomerRecord(ctypes.BigEndianStructure):
    _pack_ = 1
    _fields_ = [
        ("cust_id", ctypes.c_char * 8),          # PIC X(8) (EBCDIC)
        ("cust_name", ctypes.c_char * 30),       # PIC X(30) (EBCDIC)
        ("loan_amount", ctypes.c_char * 5),      # PIC 9(6)V99 COMP-3 (5 bytes)
        ("term_months", ctypes.c_uint16),        # PIC 9(4) COMP (2 bytes Big Endian)
    ]

def create_binary_record(record_dict: dict) -> bytes:
    rec = LoanCustomerRecord()
    # EBCDIC encoding for alphanumeric
    rec.cust_id = record_dict['IN_CUST_ID'].ljust(8).encode('cp1047')[:8]
    rec.cust_name = record_dict['IN_CUSTOMER_NAME'].ljust(30).encode('cp1047')[:30]
    
    # Pack COMP-3 for loan amount (8 digits: 6 integer + 2 decimal -> 5 bytes)
    amt_str = f"{record_dict['IN_LOAN_AMOUNT']:.2f}"
    rec.loan_amount = pack_comp3(amt_str, digits=8, signed=True)
    
    # Big Endian binary uint16 for term months
    rec.term_months = int(record_dict['IN_LOAN_TERM_MONTHS'])
    
    return bytes(rec)
```
